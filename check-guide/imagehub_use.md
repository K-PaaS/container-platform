# K-PaaS 레지스트리 사용 가이드
본 문서는 K-PaaS 레지스트리(https://registry.k-paas.org)의 계정 관리, 로그인, 이미지 허브 토큰 발급 및 사용 방법에 대한 가이드입니다.


## 계정 관리 체계

### 1. 기업 관리자 계정
- K-PaaS 센터에서 기업별로 관리자 계정을 생성하여 제공
- 기업 관리자 계정 정보 및 Private 프로젝트/이미지 저장소 정보를 기업 담당자에게 별도 공유
- 관리자 계정은 Licensed_user 등록 권한 보유
- 프로젝트는 현재 K-PaaS 센터에서 생성하여 제공 (관리자의 추가 프로젝트 생성 기능은 향후 추가 예정)

### 2. 일반 사용자 계정
- 기업 이미지에 접근이 필요한 추가 사용자는 자체 회원가입 가능
- 회원가입만으로는 기업 프로젝트 접근 불가
- 기업 관리자의 승인(Licensed_user 등록) 후 접근 가능

## 일반 사용자 회원가입 및 승인

### 1. 신규 사용자 회원가입
기업 이미지에 접근이 필요한 추가 사용자는 다음 절차로 회원가입을 진행합니다.

#### 레지스트리 접속
```sh
https://registry.k-paas.org
```

#### 회원가입 진행
- 로그인 화면에서 **"New user? Register"** 또는 **"회원가입"** 링크 클릭
- 회원가입(Registration) 양식 작성

#### 필수 입력 항목
- 아이디 (Username)
- 비밀번호 (Password, Confirm password)
- 이메일 (Email)
- 이름 (First name, Last name)
- 회사 (Company) - 소속 기업명 정확히 입력

#### 등록 완료
- 작성 완료 후 **등록/회원가입** 버튼 클릭
- 정상적으로 등록되면 로그인 페이지로 이동
- **주의: 회원가입만으로는 기업 프로젝트 접근 불가**

### 2. 기업 관리자의 Licensed_user 등록 (필수)

신규 등록된 사용자가 기업 이미지에 접근하려면 기업 관리자의 승인이 필요합니다.

#### 관리자 로그인
- 기업 관리자 계정으로 레지스트리 로그인

#### 사용자 관리 메뉴 접근
- 좌측 메뉴에서 **"Administration"** 또는 **"관리"** 선택
- **"Users"** 또는 **"사용자"** 탭으로 이동

#### Licensed_user 등록
- 신규 등록된 사용자 목록에서 승인할 사용자 선택
- 사용자 상세 정보에서 **"Licensed_user"** 권한 부여
- 또는 프로젝트 멤버로 직접 추가하여 접근 권한 부여

#### 권한 확인
- Licensed_user로 등록된 사용자만 기업 프로젝트 접근 가능
- 등록되지 않은 사용자는 로그인은 가능하나 프로젝트 접근 불가

### 3. 일반 사용자 로그인 및 접근
Licensed_user로 등록된 후 로그인하여 기업 프로젝트에 접근합니다.

```sh
# 일반 사용자 로그인 정보
Username: <회원가입한_사용자_아이디>
Password: <회원가입한_비밀번호>
```


## CLI 시크릿(Secret) 토큰 발급

### 1. 사용자 프로필 접근
- 로그인 후 우측 상단 **계정명** 클릭
- 드롭다운 메뉴에서 **"사용자 프로필"** 선택

### 2. Secret 토큰 확인
사용자 프로필 화면에서 다음 정보를 확인할 수 있습니다.

**[사용자 프로필 화면 - CLI Secret 확인]**

- 사용자명, 이메일 등 기본 정보

### 3. Secret 토큰 용도
CLI 시크릿 토큰은 컨테이너 이미지 관리 도구(Docker, Podman 등)를 통해 이미지를 push 및 pull할 때 인증에 사용됩니다.


## CLI를 통한 레지스트리 사용

### 1. Docker를 이용한 로그인
```sh
# Docker 로그인
docker login registry.k-paas.org -u <사용자ID> -p <Secret토큰>
```

### 2. Podman을 이용한 로그인
```sh
# Podman 로그인
podman login registry.k-paas.org -u <사용자ID> -p <Secret토큰>
```

### 3. 이미지 태그 및 푸시
```sh
# 이미지 태그 지정
docker tag my-app:1.0 registry.k-paas.org/<프로젝트명>/my-app:1.0

# 이미지 푸시
docker push registry.k-paas.org/<프로젝트명>/my-app:1.0
```

### 4. 이미지 풀(Pull)
```sh
# 이미지 다운로드
docker pull registry.k-paas.org/<프로젝트명>/my-app:1.0
```


## 프로젝트 관리 (기업 관리자)

### 1. 프로젝트 및 Private 이미지 저장소 제공
- K-PaaS 센터에서 기업별 Private 프로젝트 및 이미지 저장소를 생성하여 제공
- 기업 관리자 계정과 함께 프로젝트 정보 전달
- 기업 관리자는 제공받은 프로젝트를 관리하며, 현재 별도 프로젝트 생성은 불가
- **참고**: 기업 관리자의 추가 프로젝트 생성 기능은 향후 추가 예정

### 2. 프로젝트 멤버 관리
기업 관리자는 Licensed_user로 등록된 사용자를 프로젝트 멤버로 추가할 수 있습니다.

- 생성된 프로젝트 선택
- **Members** 탭으로 이동
- **+ USER** 버튼으로 Licensed_user 추가
- 역할 할당
  - **Project Admin**: 프로젝트 전체 관리 권한
  - **Developer**: 이미지 push/pull 권한
  - **Guest**: 이미지 pull만 가능

### 3. 이미지 저장소 확인
- 프로젝트 내 **Repositories** 탭에서 푸시된 이미지 목록 확인
- 각 이미지의 태그, 크기, 푸시 시간 등 상세 정보 확인 가능
- 이미지별 취약점 스캔 결과 확인


## 보안 및 관리

### 1. 토큰 보안 관리
- Secret 토큰은 비밀번호와 동일하게 취급하여 안전하게 보관
- 토큰 유출 시 즉시 재발급 권장
- 주기적인 토큰 갱신 및 관리 필요

### 2. 이미지 취약점 스캔
- Harbor는 Trivy를 통한 자동 취약점 스캔 기능 제공
- 프로젝트 설정에서 자동 스캔 활성화 가능
- 이미지 상세 페이지에서 취약점 리포트 확인

### 3. 접근 권한 관리
- 프로젝트별 접근 권한은 기업 관리자가 설정
- Private 프로젝트는 Licensed_user로 등록되고 프로젝트 멤버로 추가된 사용자만 접근 가능
- Public 프로젝트는 모든 사용자가 이미지 풀 가능 (기업 프로젝트는 Private 권장)


## 권한 체계 요약

### 1. 기업 관리자 권한
- K-PaaS에서 제공하는 기업별 관리자 계정
- K-PaaS 센터에서 생성한 Private 프로젝트 및 이미지 저장소 제공받음
- **고유 권한**: Licensed_user 등록 및 관리
- 제공받은 프로젝트 관리 (현재 신규 프로젝트 생성 불가, 향후 추가 예정)
- 프로젝트 멤버 추가 및 역할 할당
- 이미지 저장소 관리 및 보안 정책 설정

### 2. Licensed_user 권한
- 기업 관리자가 승인한 일반 사용자
- 프로젝트 멤버로 추가된 경우에만 해당 프로젝트 접근 가능
- 할당된 역할(Admin/Developer/Guest)에 따라 권한 차등 적용
- CLI를 통한 이미지 push/pull 가능

### 3. 미승인 사용자
- 회원가입은 완료했으나 Licensed_user로 등록되지 않은 사용자
- 레지스트리 로그인은 가능하나 기업 프로젝트 접근 불가
- 기업 관리자의 승인 대기 상태


## 추가 안내

### 주요 참고사항
- **기업 관리자 계정**: K-PaaS 센터에서 기업별로 생성하여 제공
- **Private 프로젝트**: K-PaaS 센터에서 기업별로 생성하여 관리자 계정과 함께 제공
- **프로젝트 생성 권한**: 현재 기업 관리자는 신규 프로젝트 생성 불가 (K-PaaS 센터에서만 생성)
- **일반 사용자**: 자체 회원가입 후 기업 관리자에게 승인 요청 필요
- **Licensed_user 등록**: 기업 관리자의 고유 권한으로, 승인 후 프로젝트 접근 가능
- **프로젝트 멤버 추가**: Licensed_user 등록 후 프로젝트별로 멤버 추가 필요
- **이미지 접근**: 프로젝트 멤버로 등록되어야 이미지 push/pull 가능

### 계정 승인 절차
1. 일반 사용자가 레지스트리에 회원가입
2. 기업 관리자에게 승인 요청 (이메일 또는 별도 채널)
3. 기업 관리자가 Administration > Users에서 Licensed_user로 등록
4. 기업 관리자가 프로젝트 Members에 사용자 추가 및 역할 할당
5. 승인된 사용자가 프로젝트 접근 및 이미지 사용
